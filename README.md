# منظومة الأرشيف الإلكتروني — هاتف ليبيا
### Hatif Libya Electronic Archive System

نظام إلكتروني متكامل لإدارة وأرشفة المراسلات والوثائق الصادرة والواردة لشركة هاتف ليبيا، يدعم العمل المكتبي وتتبع المعاملات الإدارية وتوثيقها وفق أعلى معايير الأمان والخصوصية.

---

## 🌟 أبرز الخصائص والوظائف

- **إدارة المراسلات (وارد وصادر):** تسجيل كامل لبيانات المراسلات (الرقم الإشاري، رقم التسلسل، التاريخ، الجهات المرسلة والمستلمة، الموضوع، الملاحظات).
- **إدارة المرفقات:** رفع وتخزين آمن للمستندات والصور وملفات PDF على خادم محلي خاص دون أي اعتماد على خدمات سحابية خارجية (No S3 dependency).
- **عزل الإدارات والصلاحيات:** صلاحيات متقدمة تعزل بيانات كل إدارة عن غيرها مع إشراف كامل لمدير النظام وتتبع كافة العمليات في سجل التدقيق (Audit Log).
- **البحث والفلترة المتقدمة:** بحث فوري متعدد الحقول وتصفية ذكية حسب التاريخ أو جهة الإرسال/الاستقبال أو الإدارة المختصة.
- **التقارير والتصدير:** تصدير السجلات والتقارير بصيغة CSV ونسخ احتياطي واسترجاع شامل للبيانات بصيغة JSON.
- **واجهة مستخدم عربية RTL:** تصميم حديث وسريع يدعم النمطين الفاتح والداكن ومتوافق بالكامل مع الأجهزة المكتبية والمحمولة.

## 🛠️ البنية التقنية (Tech Stack)

| المكون | التقنية المستخدمة | الوصف |
| :--- | :--- | :--- |
| **الواجهة الأمامية** | HTML5 / CSS3 / Vanilla JS | واجهة عربية RTL بدون أطر عمل خارجية ثقيلة، سريعة وخفيفة |
| **خادم الويب والوكيل** | Angie (Next-gen Nginx fork) | تقديم الملفات الثابتة وتوكيل طلبات الـ API وإدارة اتصالات HTTPS |
| **خادم التطبيق** | Node.js / TypeScript / Fastify | خادم REST API عالي الأداء مع فحص دقيق للأنواع وضوابط أمان متقدمة |
| **قاعدة البيانات** | PostgreSQL 18 | تخزين علائقي متين يدعم القيود الصارمة وسجلات التدقيق |
| **التشغيل والحاويات** | Docker Compose / GHCR | نشر مستقل عبر حاويات جاهزة مسحوبة من GitHub Container Registry |

## 🚀 التشغيل والنشر السريع (Quick Start)

النشر الإنتاجي مستقل تماماً ولا يتطلب استنساخ المستودع أو تثبيت Node.js؛ يحتاج الخادم فقط إلى **Docker Compose** وملفين:

1. **ملف الإعدادات (`.env`):**
   انسخ ملف الإعدادات من `.env.example` واضبط كلمات المرور والمنافذ المناسبة.
2. **ملف التشغيل (`docker-compose.yml`):**
   ```bash
   # سحب الصور المنشورة من GHCR
   docker compose pull

   # تشغيل المنظومة في الخلفية
   docker compose up -d
   ```

الصور الرسمية منشورة ومتاحة على:
- `ghcr.io/hlc-tripoli/archive-hlc:web-latest`
- `ghcr.io/hlc-tripoli/archive-hlc:api-latest`
